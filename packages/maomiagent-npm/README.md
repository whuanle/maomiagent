# maomiagent

Supported platforms: Windows x64, Linux x64, macOS x64, macOS arm64.

Install the desktop launcher package globally:

```bash
npm i -g maomiagent
```

Launch MaomiAgent:

```bash
maomiagent
```

Compatibility alias:

```bash
maomi-agent
```

Update the installed package:

```bash
npm update -g maomiagent
```
